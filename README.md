Project Overview

This project demonstrates the development of a Retail Sales Data Agent using Databricks and AI-powered data analysis tools. The objective of the project was to create an intelligent agent capable of interacting with retail sales data using natural language questions and generating business insights from the dataset.

The project involved uploading and preparing a retail sales dataset, configuring a Data Agent, testing business-related questions, validating AI-generated responses, and documenting the full workflow.

Objectives

* Upload and prepare a retail sales dataset in Databricks
* Create and configure a Retail Sales Data Agent
* Connect the dataset to the AI agent
* Ask business-related analytical questions
* Generate business insights from the dataset
* Validate the accuracy of AI-generated responses
* Document the full development process


Technologies Used

* Databricks
* SQL
* Python
* AI Data Agent
* GitHub
* Large Language Models (LLMs)

Dataset Information

The dataset contains retail sales transaction data including:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount


Project Workflow

1. Upload Dataset

The retail sales dataset was uploaded into Databricks using the Catalog section.

2. Create Database and Table

A database, schema, and retail sales table were created to organise the dataset.

3. Configure the Data Agent

A Retail Sales Data Agent was created and connected to the retail sales table.

4. Agent Instructions

Instructions were added to guide the agent on how to answer business-related questions accurately.

5. Business Questions

The Data Agent was tested using multiple business analysis questions related to:

* Product performance
* Sales trends
* Customer behaviour
* Revenue analysis
* Gender and age group purchasing trends

6. Validation

SQL queries and manual checks were used to validate the accuracy of the Data Agent responses.

Key Insights

* Certain product categories generated higher revenue compared to others.
* Monthly sales trends showed seasonal buying behaviour.
* Customer purchasing behaviour varied across gender and age groups.
* The AI Data Agent successfully generated business insights using natural language queries.

Business Recommendations

* Increase promotions for lower-performing product categories.
* Focus marketing efforts on high-value customer groups.
* Use sales trends for better inventory planning.
* Continue monitoring customer behaviour for business growth opportunities.
